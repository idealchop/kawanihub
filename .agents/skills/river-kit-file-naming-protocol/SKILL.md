# File naming

Copyright (c) 2026 River Tech. All rights reserved.

All filenames are `kebab-case.ext`.

- `login-form.tsx`
- `use-items.ts`
- `items-handler.ts`

Exceptions: `README.md`, `LICENSE`, `COPYRIGHT`, `package.json`, `SKILL.md`.
